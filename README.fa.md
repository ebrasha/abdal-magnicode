## 🚀 معرفی افزونه

**Abdal MagniCode** افزونه‌ای حرفه‌ای برای مرورگر فایرفاکس است که با هدف جایگزینی ابزار سنتی Inspect Element طراحی شده است. این ابزار با استفاده از ذره‌بین دایره‌ای و بزرگنمایی زنده، امکان مشاهده و تحلیل سریع ساختار کد HTML صفحات وب را به روشی جذاب و ساده فراهم می‌کند.

ابزار بسیار مفیدی برای توسعه‌دهندگان، تحلیل‌گران امنیت و حتی کاربران آموزشی که می‌خواهند بدون باز کردن DevTools، کدها را بررسی کنند.

---

## ✨ قابلیت‌ها

- 🔍 **ذره‌بین زنده:** بزرگ‌نمایی آنی اطراف نشانگر موس با اندازه و مقیاس قابل تنظیم
- 💻 **نمایش کد HTML:** نمایش زنده ساختار HTML زیر ذره‌بین
- 🎯 **کپی خودکار:** قابلیت کپی سریع کد HTML عنصر کلیک‌شده
- 🎨 **هایلایت نحوی:** رنگ‌بندی اجزای HTML برای خوانایی بهتر
- ⚙️ **تنظیمات پیشرفته:** رابط کاربری شیشه‌ای با امکان پیکربندی
- 🛡️ **سازگاری کامل:** ایزولاسیون CSS برای جلوگیری از تداخل با سایت‌ها
- ⌨️ **میانبرها:** ESC برای بستن، Ctrl+S برای ذخیره، Ctrl+R برای بازنشانی

## 🧩 روش نصب


### 🔹 نصب از مخزن رسمی افزونه‌ها

1. فایرفاکس را باز کنید
2. به مسیر `about:addons` یا **مدیریت افزونه‌ها** بروید
3. نام **Abdal MagniCode** را جستجو کنید
4. روی دکمه **نصب** کلیک کنید و از امکانات افزونه بهره‌مند شوید
